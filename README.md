# 🎉 Evently — Flutter Event Application

![Flutter](https://img.shields.io/badge/Flutter-3.x-blue)
![Dart](https://img.shields.io/badge/Dart-3.x-blue)
![Firebase](https://img.shields.io/badge/Firebase-Enabled-orange)
![Provider](https://img.shields.io/badge/State%20Management-Provider-blue)

A modern Flutter event application that allows users to browse events, view event details, and manage their favorite events through a clean and responsive user experience.

The application uses Firebase for authentication and cloud data management, Provider for theme and language management, and local storage to persist user preferences.

---

## 📱 Features

* 🎉 Browse Events
* 📄 View Event Details
* ❤️ Add Events to Favorites
* 🗑️ Remove Events from Favorites
* 🔥 Firebase Authentication
* ☁️ Cloud Firestore Integration
* 🌙 Dark & Light Theme
* 🌍 Multi-Language Support
* 💾 Local Storage for User Preferences
* ⚡ Provider State Management
* 📱 Responsive UI
* 🎨 Modern Design
* 🚀 Smooth Navigation

## 🧠 State Management

The application uses **Provider** for managing application state.

Provider is mainly used for:

* 🌙 Theme Management
* 🌍 Language Management
* ❤️ Favorites State
* 🔄 Updating UI based on user actions

### Theme Management

Users can switch between:

* ☀️ Light Mode
* 🌙 Dark Mode

The selected theme is saved locally so the preference remains after restarting the application.

### Language Management

The application supports multiple languages, allowing users to change the application language.

The selected language is also stored locally for persistence.

---

## 🔥 Firebase Integration

Firebase is used as a core part of the application.

### Firebase Authentication

Users can:

* Create an account
* Login
* Logout
* Authenticate securely using Firebase Authentication

### Cloud Firestore

Cloud Firestore is used to store and manage user-related data.

The application uses Firestore to manage favorite events.

Users can:

* ❤️ Add an event to favorites
* 🗑️ Remove an event from favorites
* 📋 Retrieve their favorite events

---

## 💾 Local Storage

Local storage is used to save user preferences locally.

It is mainly used for:

* 🌍 Selected Language
* 🌙 Selected Theme

This allows the application to remember the user's preferences even after restarting the application.
